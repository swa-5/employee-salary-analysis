# Employee Salary & Performance Analysis

## 📌 Project Overview
This project analyzes employee salary and performance data using SQL and Python.

## 🛠 Technologies Used
- SQLite3
- Python
- Pandas
- Matplotlib

## 📊 Features
- Average salary per department
- Highest paid employee analysis
- Performance-based salary increment simulation
- Data visualization

## 🚀 How to Run
1. Run SQL script in MySQL.
2. Install requirements:
   pip install -r requirements.txt
   3. Run:
      python project.py

      ## 📈 Business Value
      Helps management make data-driven decisions related to salary structure and performance incentives.
